## Provenance, rights and packaging

Each entry contains independently written MIT prose, its own `LICENSE.txt`, explicit overlap and immutable inspiration links. Upstream Apache-2.0/NOTICE and MIT files were inspected during research; no upstream expression, code, assets or helpers are redistributed. An adapted method is not a patched vendored entry, and its MIT notice does not relicense any upstream material.

Skills have standard `SKILL.md` frontmatter. Workflows retain the catalog's `WORKFLOW.md` form. The platform-map reference is bundled inside level-design; no consumer needs access to this checkout or another installed entry. There are no new runtime dependencies or plugin manifests.

## UI category

The existing `game-design` tag is authoritative for category membership. The browser presents a dedicated Game design tree group and Category filter, including the five new entries and existing mmorpg-design. The category intersects with existing type/source/host/evidence/search filters and clear/reset behavior. Underlying types, item links and installation paths are preserved.

Each ordinary item has one primary tree placement; Featured remains an intentional additional listing. Custom and Experimental placement retains precedence, while those items can still match a topic filter if later tagged. No new metadata schema or content type is required.

## Validation and evidence limits

Category tests cover the actual six admitted entries, skill/workflow identity, primary-placement uniqueness, category clearing and existing special-group precedence. Repository validation checks metadata, reference closure, licenses and generated-index freshness. The site build and local browser checks assess rendered grouping, category/type filtering, reset and entry navigation.

These are implementation and structural checks. No implicit activation trial, actual player study, prototype gameplay experiment or matched agent-outcome evaluation was performed. Every new entry starts at `reviewed`, with conservative usefulness for typical software projects. Catalog admission does not install any guidance into a consumer project or run its tasks.
