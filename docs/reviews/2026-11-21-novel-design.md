# Creating Novel Designs

Reviewed November 21, 2026 by Codex, the skill’s author, using [human-v1](../ratings.md). The baseline is host frontend-design guidance or a direct request for a distinctive design with the same brief and assets.

The initial review covered Jakob Meyer’s unaverage design README and public project site. The upstream skill files and testing document were unavailable through the sources checked. The skill distills the documented method of building around concrete material, comparing equivalent sketches, and replacing interchangeable elements according to their function. The initial tool-lending example and name-swap test were written for the catalog.

The follow-up [art-direction scout](../research/2026-11-21-catalog-scout.md) adds reference abstraction, a one-sentence concept check, proportional expression, and a check on the hardest relevant application. The package uses original prose and has no runtime dependencies. The curator grades remain provisional and unchanged after the follow-up.

| Criterion | Grade (0–4) | Rationale |
| --- | --- | --- |
| Practical value | 3 | Gives open-ended design briefs a concrete way to derive and compare directions. |
| Dependability | 2 | The method depends on the quality of the material and the agent’s visual judgment. The name swap is a heuristic for specificity. |
| Cognitive ease | 3 | Keeps discovery short and compares one surface at the same level of finish. |
| Human control | 4 | Respects supplied direction and lets the user choose when the brief calls for options. |
| Adoption cost | 3 | Single entrypoint with no setup. Comparing and checking renders still takes design time and may need tools for the target medium. |
| Compatibility | 3 | Works across hosts and media. The available preview tools determine what can be checked. |
| Upkeep | 4 | The procedure has no integrations, style library, or tool versions to maintain. |

Admit as experimental at evidence level `reviewed`. To evaluate the design method, give the skill and the baseline the same project material and compare rendered work for subject fit, clarity, and distinctiveness. Include at least one brief with a fixed direction to check whether the skill avoids unnecessary exploration.
