# Game design methods

The catalog browser groups entries tagged `game-design` under **Game design**. The Category filter can be combined with Type, Source, Host, Evidence and search. A topic category does not change an entry's installable type or run any workflow.

Select the methods that match the current decision. A mechanic proposal may need one experiment; an established game's loot review may need data analysis and later player observation. The category is not an install-all collection or a mandatory production pipeline.

All five new methods are independent adaptations of the [reviewed research sources](research/2026-10-29-catalog-scout-2.md). They preserve existing engines and project conventions, require no upstream studio runtime and introduce no automatic agents, hooks or services. Structural checks and browser verification do not establish better gameplay or agent design outcomes. Every entry remains at evidence level `reviewed`.
