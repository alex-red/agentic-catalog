For a reproducible defect, use a focused repair and task verification. For an unresolved question about human comprehension or findability, prepare a real study. When records already exist, analyze them before collecting more. An agent walkthrough, a heuristic review and a participant study support different kinds of claims.

For visual implementation alternatives, see [frontend design options](frontend-design-options.md). Accepted design systems and project conventions remain authoritative. None of the options above requires replacing them or installing the other entries.

## Installation boundaries

The adapted payloads contain all instructions they require and their own MIT license. Other entries in their metadata are optional relations, not hidden dependencies. The workflow is a procedure selected for a task, not a hook or background loop. Human-interface-design includes all three local references; preserve them when copying the skill. Its source links provide attribution and platform detail rather than remote instructions to load at runtime.

Linked entries require fetching their pinned sources and assembling the complete selected payload described in `install`. Check existing destinations first. For Anthropic synthesis, retain `product-management/LICENSE`, copy `product-management/CONNECTORS.md` locally, and change the installed entrypoint's `../../CONNECTORS.md` link to `./CONNECTORS.md`. Add a prominent packaging-change notice and source pin in the installed file; no other method changes are prescribed. Do not copy the plugin's MCP configuration. The scoped license was read at the exact pin; the separate root license's trailing anomaly remains recorded rather than silently discarded from research history.

Intent's default selection here is its complete core subtree. A specialist route does not make an unavailable skill present. Review and select any additional sibling at the same repository revision; do not implicitly install the eighteen-skill package, six agents or platform integrations. Its sample-size heuristics are not statistical guarantees, and shared reports must retain material limitations even where upstream favors terse artifacts.

All new entries start at `reviewed`. Ratings reflect source and curator review, not measured UX improvement or verified trigger performance. See the [research](research/2026-10-29-catalog-scout.md) and [admission record](research/2026-10-29-ux-admission.md).
