About this catalog

A curated, rated catalog of agent guidance for coding agents, focused on Claude Code and Codex: . Agents read the same data from llms.txt and catalog/index.json, or through the agentic-catalog skill.

  • Score = (2 × usefulness + quality + portability + novelty) / 5. Novelty is value beyond host built-ins.
  • Evidence, weakest to strongest: reviewed, used, tested, evaluated. Scores are curator judgment unless evidence is evaluated.
  • Source: original or adapted (written here), vendored (pinned upstream copy), or linked (upstream only).

Filter by type or tag, or search titles, summaries, and use cases. Press / to search, ↑/↓ to step through items, and Esc to close.
