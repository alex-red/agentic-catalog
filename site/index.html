About Agentic Catalog

Curated Agent Guidance

A curated, rated catalog of skills, rules, workflows, hooks, subagents, and MCP servers for coding agents (Claude Code, Codex, and portable formats). Read directly by agents via llms.txt or the agentic-catalog plugin skill.

Shortcuts: ⌘ / Ctrl K commands · / filter catalog · ↑↓ navigate · Esc reset

Rubric & Evidence Levels

  • Score: (2 × usefulness + quality + portability + novelty) / 5. Novelty measures lift beyond host built-ins.
  • Evidence tiers: reviewed (curator read) → used (observed in session) → tested (trigger test) → evaluated (outcome eval).
  • Source: original/adapted (authored here), vendored (pinned upstream copy), or linked (external reference).
