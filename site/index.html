Agentic Rules

About this library

Agent guidance for Claude Code and Codex that is kept only when it measurably helps. Each component targets a failure observed in real projects and is compared against the host's default behavior before it ships. Status: experimental: , piloted on one project.

  • Skills load on demand when a request matches their description (for example, debugging a failing test). They can include reference files, shown as tabs in the viewer.
  • Rules are short, always-on instructions. They are not part of the plugin: copy them into .claude/rules/ (Claude Code) or merge them into AGENTS.md (Codex).
  • Profiles are bundles of rules and skills that go together for one purpose.

How to browse: start with a profile to see a coherent set, then open its skills and rules. Filter by kind or tag, search descriptions, and click an item to read its source as plain text. Press / to search, ↑/↓ to step through items, Esc to close. Every view has a shareable link. Install steps are in docs/installation.md.
