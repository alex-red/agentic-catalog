# Verification evidence

Check a change where its effect appears. For anything a user would see, use the running app when one is available, such as a dev server or browser pane the user already has open. Not being allowed to start a server is not a reason to skip a check in an app that is already running. If no running app is available, name the visible behavior that remains unchecked and the quickest way to check it. For a defect, reproduce it before changing code when practical, and repeat the check afterward.
