# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

### Added

- Catalog of 40 rated entries (skills, rules, workflows, hooks, subagents, MCP servers, plugins) and four collections.
- `agentic-catalog` discovery skill, shipped as a Claude Code and Codex plugin.
- Catalog browser with tree navigation, sort and filter comboboxes, and a Featured group.
- Evaluation harness for trigger and outcome runs.
- Bulk selection in the browser, generating a reviewable install script and an `agentic-catalog.yaml` config (in `.agents/` for a repository or `~/.agents/` for all projects) that can be loaded again to update or remove entries.
