# Workflows

The first available workflow is [bug fixing](../skills/ar-systematic-debugging/SKILL.md), owned by `ar-systematic-debugging`: establish a reproduction, test a diagnosis, correct the cause, and verify the result.

Invoke the skill through the host's skill mechanism. This index is for people browsing the library; it is not an executable workflow and does not automatically enter an agent's context.

Quick-change and feature-development recipes will arrive with the implementation skill described in [the plan](../PLAN.md). No runner, hooks, or automatic retry loop is provided by this scaffold.
