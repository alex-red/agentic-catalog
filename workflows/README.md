# Workflows

Available workflows:

- [Retrospective](../skills/retrospective/SKILL.md): turn the stumbling blocks of finished work into project instructions, skills, scripts, or checks that will load, and verify that new skills trigger.

The bug-fixing workflow is [bug fixing](../skills/systematic-debugging/SKILL.md), owned by the `systematic-debugging` skill: establish a reproduction, test a diagnosis, correct the cause, and verify the result.

Invoke it through the host's skill mechanism. This index is for people browsing the library. It is not executable and does not enter an agent's context.

Planning, implementation, and review workflows are covered by host built-ins (plan mode, default agent behavior, review commands), so the library does not duplicate them. See the [plan's inventory](../PLAN.md#inventory).
